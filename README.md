# Markowitz Portfolio Optimization

Portfolio optimization implementation using the Markowitz Mean-Variance Optimization framework in Python.

## Overview

This project implements Modern Portfolio Theory (MPT) developed by Harry Markowitz, which aims to construct an optimal portfolio by balancing expected return and risk (variance).

## Features

- Mean-Variance Optimization using `cvxopt`
- Real-time stock data download using `yfinance`
- Portfolio risk-return analysis
- Efficient frontier visualization
- Optimal portfolio allocation calculation

## Requirements

- Python 3.7+
- numpy >= 1.21.0
- pandas >= 1.3.0
- matplotlib >= 3.4.0
- cvxopt >= 1.2.0
- yfinance >= 0.1.87

## Installation

The notebook includes automatic dependency installation. Alternatively, you can install manually:

```bash
pip install numpy pandas matplotlib cvxopt yfinance
```

## Usage

Open `Markowitz.ipynb` in Jupyter Notebook or JupyterLab and run the cells sequentially.
